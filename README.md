# rules_and_ops — управляющая рамка для AI-проектов (передаточный пакет)

> Кому: ведущему проекта familycode. Что это: готовый набор правил, протоколов
> и механизмов контроля для работы над проектом с участием AI-агентов и разных
> инструментов (Codex, Cursor, VS Code, Claude и др.). Сам проект отсюда
> НЕ правится — вы применяете пакет у себя по шагам из
> `project-familycode/ONBOARDING.md`.

## Устройство: два слоя

- **`core/`** — универсальное ядро (английский): рамка, кодификация, операционные
  правила, протокол сессий, гейты, CI-контроль, адаптеры под инструменты.
  Ядро не содержит ничего специфичного для конкретного проекта — из него
  собирается стартер-пак для любых будущих проектов такого рода.
- **`project-familycode/`** — привязка ядра к вашему проекту: готовые файлы,
  которые вы сами кладёте в репозиторий, и пошаговая инструкция внедрения.

## Что даёт рамка (коротко)

1. **Правила читают все инструменты.** Один файл `AGENTS.md` в корне проекта
   понимают Codex, Cursor, VS Code/Copilot, Claude и ещё десятки инструментов;
   дубль `CLAUDE.md` — подстраховка. Правила лежат в одном месте, адаптеры —
   только указатели.
2. **Протокол сессий.** Каждая рабочая сессия агента регистрируется строкой
   в `SESSIONS.md` на main (видно: кто, когда, в какой ветке, зачем), работа идёт
   в ветке `session/<дата>-<тема>`, созданные артефакты коммитятся сразу,
   в main всё попадает только через pull request с проверками.
3. **Механический контроль.** Локальный pre-commit гейт (кодировки, BOM,
   пиктограммы, абсолютные пути) плюс тот же контроль на стороне GitHub
   (Actions на каждый PR) — правила держит инструмент, а не память людей.
4. **Память репозитория.** Стандартная структура: решения, активный контекст,
   заметки сессий — чтобы контекст переживал смену чатов, инструментов и людей.

## С чего начать

1. Прочитать `project-familycode/ONBOARDING.md` (пошаговое внедрение).
2. Скопировать перечисленные там файлы в проект, включить гейт одной командой.
3. Первая рабочая сессия — по протоколу: регистрация в `SESSIONS.md`, ветка, PR.

Карта всего пакета — в `AGENTS.md`. Вопросы и решения по пакету — в `memory/decisionLog.md`.
