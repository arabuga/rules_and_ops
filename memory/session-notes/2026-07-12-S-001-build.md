   для копирования 1:1; GitHub Actions исполняет workflows только из
   корневого `.github/` репозитория, так что в пакете он инертен.
4. **Скелет пакета чист:** все bootstrap-файлы прошли гейт без замечаний;
   расхождений скелета со стартером не обнаружено.
5. **Разведка клона:** проект документальный, канон в `docs/concept/`,
   рабочая зона `docs/workbench/` со статусной дисциплиной
