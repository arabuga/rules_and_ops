# memory — память репозитория familycode

> Человеческий слой (русский). Структура — по спецификации памяти рамки;
> усечения фиксируются решением в `decisionLog.md`.

| Файл / каталог | Что |
|---|---|
| `decisionLog.md` | решения по работе в репо (D-серия), судит владелец проекта |
| `activeContext.md` | где мы сейчас, открытые развилки |
| `session-starters/` | задания на агентские сессии |
| `session-notes/` | заметки-сдачи сессий (матрица верификации обязательна) |

Слой памяти дополняет, а не заменяет существующий порядок проекта:
канон живёт в `docs/concept/`, рабочие материалы и их статусы — в
`docs/workbench/`, контекст-бутстрап — в `PROJECT_CONTEXT.md`.
Правило: память — короткие записи и ссылки, не дубли содержимого.
